## 4. La solución: Pitchavi

### Qué hace Pitchavi

Pitchavi ayuda a responder una pregunta clave:

> *¿Qué oportunidades hay para innovar o exportar un producto agroindustrial, y con qué información se puede respaldar esa decisión?*

A diferencia de un buscador común o de un chat automatizado, Pitchavi:

- **Guarda la información original** de cada fuente consultada, para poder revisarla después.
- **Organiza los hallazgos** de cada búsqueda en un solo lugar.
- **Distingue** entre un dato comprobado, una interpretación y una recomendación.
- **Advierte** cuando falta información o una fuente no responde, en lugar de inventar conclusiones.

### Lo que ya está listo

Esto no es un dibujo ni una maqueta. Es un sistema inicial ya probado:

| Función | Estado |
|---|---|
| Registro de cada consulta de investigación | Lista |
| Búsqueda automatizada de evidencia científica | Lista |
| Complemento de datos bibliográficos | Lista |
| Respaldo verificable de la información consultada | Lista |
| Pruebas de funcionamiento | Realizadas |
| Diseño completo para ampliaciones futuras | Documentado |

**Mensaje para Dirección:** el mayor riesgo — saber si la herramienta puede funcionar — ya está resuelto. Los tres meses se enfocan en **adaptarla al CITE, ampliarla con un segundo tipo de información y dejarla en manos del equipo**.

### Cómo se verá el piloto en 3 meses

```text
    Equipo de I+D+i del CITE
              │
    Producto y mercado definidos
    (ejemplo: arándono → EE.UU.)
              │
         Pitchavi
              │
    ┌─────────┼─────────┐
    │         │         │
 Ciencia   2.º tipo   Informe
 (listo)   de info    para mipymes
              │
      Capacitación y entrega
```

**El segundo tipo de información** se define en el primer mes con I+D+i. Puede ser:

| Tipo de información | Para qué sirve al CITE |
|---|---|
| **Patentes** | Ver qué innovaciones ya están protegidas y quién las desarrolla |
| **Comercio exterior** | Conocer flujos de exportación e importación por producto |
| **Tendencias de mercado** | Detectar interés y cobertura en noticias y medios |

En tres meses, con un solo especialista, es realista llegar a un **piloto sólido con dos tipos de información y reportes útiles**. Una plataforma completa con todas las funciones sería una fase posterior. Se plantea así con transparencia para generar confianza.

### 6.1 Plus del servicio — CLI Market *(incluido sin costo adicional)*

Soy **founder de CLI Market** ([cli-market.dev](https://cli-market.dev)), plataforma de inteligencia de precios y catálogos para productos agroindustriales. Como complemento a Pitchavi — y **sin sumar al costo del contrato** — el CITE recibe:

| Plus incluido | Qué obtiene el CITE |
|---|---|
| **Comparativa de precios de referencia** | Precios normalizados por kg o litro para el producto del caso piloto, útiles para fijar estrategia comercial |
| **Indexación piloto de catálogo** | Hasta **3 productos o subproductos** de mipymes acompañadas por el CITE, publicados en CLI Market sin costo de integración |
| **Ficha técnica digital** | Estructura de datos para subproductos (granulos nativos, orujos, biomasa) con respaldo del laboratorio del CITE |
| **Taller de comercialización digital** | 1 sesión de 2 horas para Transferencia Tecnológica y mipymes del caso piloto |
| **Puente investigación → mercado** | Tras la Ficha de oportunidad (Pitchavi), datos concretos de precio y visibilidad para decidir el siguiente paso comercial |

```text
Pitchavi responde:  "¿Conviene innovar o exportar?"
CITE valida:        "¿El producto cumple calidad?"
CLI Market apoya:   "¿A qué precio compite y cómo lo encuentra el comprador?"
```

**Qué no promete este plus:** no sustituye la venta ni garantiza contratos comerciales. Sí entrega **información de mercado y un canal digital de visibilidad** que hoy las mipymes del CITE no tienen de forma sistemática.

> Este plus convierte la propuesta en un recorrido más completo: **investigar → validar → comercializar**, con herramientas distintas en cada etapa y un solo especialista coordinando el piloto.

## Anexo A — Evidencia del prototipo funcional Pitchavi v0.1.0

Este anexo documenta el **avance ya construido y comprobado** que respalda la propuesta. No es un diseño en papel: es un sistema inicial operativo, con pruebas automáticas y documentación de diseño.

### A.1 Resumen del prototipo

| Dato | Detalle |
|---|---|
| **Nombre** | Pitchavi |
| **Versión** | 0.1.0 |
| **Estado** | Prototipo funcional validado |
| **Lenguaje** | Python 3.11+ |
| **Qué hace hoy** | Busca evidencia científica, guarda la información original de cada fuente y genera un informe trazable por consulta |

### A.5 Flujo comprobado del prototipo

```text
1. El analista ingresa: producto, mercado destino, aplicación, periodo
2. El sistema crea un registro de investigación único
3. Consulta OpenAlex → guarda respuesta original → extrae publicaciones
4. (Opcional) Consulta Crossref → vincula al mismo artículo sin duplicar
5. Devuelve informe con evidencia, fuentes y fecha de consulta
6. Si algo falla → el sistema lo reporta con detalle, sin ocultar el error
```
