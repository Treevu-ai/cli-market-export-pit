# Canvases CLI Market PIT

Los archivos `.canvas.tsx` de esta carpeta son copias de respaldo en el repo.

Para que Cursor los detecte y abra al lado del chat, cópialos a la carpeta gestionada por el IDE:

**Windows**

```
%USERPROFILE%\.cursor\projects\<nombre-del-workspace>\canvases\
```

**macOS / Linux**

```
~/.cursor/projects/<nombre-del-workspace>/canvases/
```

Ejemplo en Windows (usuario `acuba`):

```
C:\Users\acuba\.cursor\projects\cli-market-export-pit\canvases\pit-agentic-system.canvas.tsx
```

El `<nombre-del-workspace>` coincide con la carpeta que ves en `.cursor/projects/` al abrir este repo en Cursor (puede ser el nombre del repo o un hash).
