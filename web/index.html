Preguntas frecuentes

¿Qué productos pueden analizarse?

Alimentos, ingredientes funcionales, snacks, bebidas y productos agroindustriales con consulta en inglés o español.

¿Qué fuentes utiliza PIT?

OpenAlex, Crossref, PubMed, EPO OPS, UN Comtrade, CLI Market, OpenFDA, GDELT y más. Cada respuesta se almacena con checksum.

¿Analizan mercados internacionales?

Sí. El mercado destino se define con código ISO (ej. US, PE) y filtra conectores regulatorios y de comercio.

¿Qué recibe el cliente?

Reporte JSON/PDF con score, dominios, claims y fuentes. Opcionalmente, Ficha de Oportunidad vía capa de agentes.
